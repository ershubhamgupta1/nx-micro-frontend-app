Publish shared-common package to GitHub Packages

Package name: @ershubhamgupta1/shared-common

1) Update the version in libs/shared/common/package.json

2) Build the shared package

  npx nx build shared-common

3) Publish locally to GitHub Packages using PAT

  export GH_PACKAGES_TOKEN=<your_github_pat_with_write_packages>
  printf "@ershubhamgupta1:registry=https://npm.pkg.github.com\n//npm.pkg.github.com/:_authToken=${GH_PACKAGES_TOKEN}\n" > ~/.npmrc
  cd dist/libs/shared/common
  npm publish

4) Push code changes to GitHub

  git add .
  git commit -m "chore: prepare shared-common package publish"
  git push origin main

5) Publish using GitHub Actions by pushing a tag

  git tag shared-common-v0.1.0
  git push origin shared-common-v0.1.0

6) Or trigger the workflow manually from GitHub Actions

  Workflow name: Publish Shared Common Package

7) Install the package from GitHub Packages in another project

  npm install @ershubhamgupta1/shared-common

8) If installing from another private project, configure npm registry first

  printf "@ershubhamgupta1:registry=https://npm.pkg.github.com\n//npm.pkg.github.com/:_authToken=${GH_PACKAGES_TOKEN}\n" > ~/.npmrc
  npm install @ershubhamgupta1/shared-common
