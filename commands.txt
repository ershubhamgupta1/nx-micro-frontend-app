Publish shared component package to npm

Package name: @ershubhamgupta/shared-component

1) Make sure you own the npm scope @ershubhamgupta or have publish access to it

2) Update the name/version in libs/shared/common/package.json

3) Build the shared package

  npx nx build shared-common

  Important: if you change the package name or version, build again before publish
  so dist/libs/shared/common/package.json gets updated

4) Login to npm locally if you want to publish from your machine

  npm login

5) Publish locally to npm

  cd dist/libs/shared/common
  npm publish --access public --otp=<6_digit_code>

6) Push code changes to GitHub

  git add .
  git commit -m "chore: prepare shared-component package publish"
  git push origin main

7) Publish using GitHub Actions by pushing a tag

  git tag shared-component-v0.1.0
  git push origin shared-component-v0.1.0

8) Or trigger the workflow manually from GitHub Actions

  Workflow name: Publish Shared Component Package

9) GitHub Actions requirement

  Add NPM_TOKEN in GitHub repository secrets
  NPM_TOKEN must be an npm publish token that can bypass 2FA for CI publishing

10) Verify the package on npm

  npm view @ershubhamgupta/shared-component

11) Install the package from npm in another project

  npm install @ershubhamgupta/shared-component

12) Important

  If npm publish fails, first verify that the scope @ershubhamgupta exists in npm
  and that your npm user/token has publish permission for that scope.
  If your npm account has 2FA enabled, local publish requires --otp and CI requires
  an npm token with bypass 2FA permission.
